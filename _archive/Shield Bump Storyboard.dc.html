3 · AIR RIPPLE — 4-FRAME LOOP @ 90MS
The "currently invincible" state cue. Three rings alive at once, each spawning at r=4 and dying at r=15, offset a third of a loop apart so one is always fresh. Front arc spans 140°, side arcs are clipped to 50° at 0.8× radius so the car never looks encircled. Brightness steps down with ring age; the oldest is dashed. Anchor is the front bumper centre — the dotted box shows a 14×24 footprint for scale, nothing more.

SHEET SUMMARY
Sizes and anchors
Thruster 20×22, anchor top-centre (rear bumper). Guard 20×11, anchor bottom-centre (front bumper). Ripple 40×34, anchor bottom-centre. Explosion 32×32, anchor centre. Tracer 20×44, anchor bottom-centre (muzzle). Tank cue 28×22, anchor bottom-centre.
Stacking
All seven are independent and can overlap freely. Sustained state = thruster loop + ripple loop (or tank cue). A hit spawns one explosion instance; several can run at once during the window without touching the loops.
Draw order
Ripples and thruster below the vehicle sprite, guard below it too so the nose silhouette stays intact, explosions and tracer above everything.
Timing
Guard extend 300ms, loops run until the bar empties, explosion 450ms per instance, guard retract 350ms, tracer 240ms. Impacts never gate the loops or the mode timer.
